## 18 个 FAIL 归因

### A. Agent 端基础设施故障（7 题）— 与知识库无关
| 题 | 原因 |
|----|------|
| EV-021 / 027 / 060 / 065 / 071 / 077 | `Multi-agent token budget exceeded: used=501k~572k budget=500000`。预算按 trace 计、每题独立，**单题烧超 50 万 token** = LLM 重试风暴（fallback + 同模型退避重试不断重发增长中的上下文） |
| EV-058 | `400 invalid_request_error: Messages with role 'tool' must be a response to a preceding message with 'tool_calls'` — 重试路径/FAQ fast-path 下消息序列断裂（tool 消息无前置 assistant 轮次），属 agent 端 bug |

> 这两类问题若修复（提高预算或修复消息序列），7 题可回补，得分可回到 ~84+。

### B. 回答格式不符合严格匹配（8 题）— 数据在，格式不认
EV-003 / 010 / 035 / 043 / 050 / 055 / 056 / 061：
- 回答以 Markdown 表格呈现（`| **costGold** | 20000 |`），数据与字段都在；
- 严格打分器只认内联「`字段=值` / `字段:值` / `字段 值`」格式 → 判 `field missing`；
- 例外：EV-050（掉落权重合计）回答中**连字段名 `weightTotal` 都没出现**，纯裸数字 → 真实格式遵守失败。

### C. 打分器首匹配歧义（2 题）

| EV-059 | 回答含 `day 1`（首日描述），题目问第 14 天 → 取首个匹配 → 误判 |

## 结论与建议
1. **知识库 v0.2 检索链路健康**：47/47 数值审计一致；除 7 题基础设施故障外，其余失败均为格式/匹配层问题，无系统性检索错误；anti_hallucination 7/9 命中（拒绝 H017/SK073/BF031/GP009 均正确）。
2. **agent 端两个真问题**：① 单题 token 重试风暴（500k 预算被打穿）；② tool 消息序列断裂（provider 400）。建议优先排查 LLM 重试路径。
3. **格式纪律**：eval 提示词已要求「字段=值」内联格式，agent 倾向输出人类可读表格。若需机器可解析答案，需强化提示词约束或放宽打分器（接受表格行列解析）。
